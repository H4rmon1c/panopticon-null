# Saguache document-index profile

The [Town of Saguache documents page](https://www.townofsaguache.org/documents)
lists town-board agendas and minutes, including the
[January 13, 2025 minutes](https://www.townofsaguache.org/uploads/january_13_2025_minutes_1.pdf).
The minutes name board members and give aggregate vote counts for some
motions. Those counts do not establish each member's position. This profile
does not claim a relevant surveillance decision, contract, or named vote.

[`co-saguache.toml`](../configs/states/co-saguache.toml) binds that exact HTML
index to a separate same-host `/uploads/` PDF path policy and geography ID
`us-co-place-0867005`. It is **unscheduled and uncaptured**. Current
source-level robots and terms reviews are required before the private
collector can archive the index or any linked PDF. The public browser reads
no live data from this source.
