# Moffat and Simla document indexes

The [Town of Moffat Board of Trustees page](https://www.townofmoffatco.gov/pages/boards-committees) directs readers to its [official documents index](https://www.townofmoffatco.gov/documents) for agendas, minutes, and packets. The [Town of Simla documents index](https://townofsimla.com/documents) lists Board of Trustees meeting minutes. Both pages link same-host PDFs under `/uploads/`. Their exact HTML index and upload prefixes have separate, bounded source configurations in [`co-moffat.toml`](../configs/states/co-moffat.toml) and [`co-simla.toml`](../configs/states/co-simla.toml), mapped to the Colorado geography roster.

These are **unscheduled source profiles**, not investigated or published cases. Source-policy review, private fetch receipts, and candidate archive work remain before any document can support a claim. The repository includes two exact anchor excerpts from each page and each page's observed SHA-256 digest as offline parser regression fixtures. The live page can change; the digest is a recorded observation, not a freshness claim.

The index parser accepts only HTTPS same-host PDF links under the separately configured `/uploads/` prefix, with no query, fragment, encoded path segment, or path escape. The candidate list stays private and is rederived from the digest-bound HTML before an independently reviewed PDF fetch. A meeting described as “unanimous” or “all in favor” does not establish each person's vote unless the official record supplies a named position for each person. Neither town currently has a surveillance decision, contract, named vote, role/term chain, or portrait established in this repository.
