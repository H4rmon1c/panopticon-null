# Colorado geography worklist

Run `python3 web/panopticon-terminal/scripts/build-colorado-worklist.py --output /tmp/colorado-worklist.csv` from the repository. It produces one row for each of the 4,111 archived geography entries. The CSV joins the neutral roster to the scheduled HTML calendar sources, version 2 manifests, and the current static public snapshot through explicit stable IDs. [The calendar mapping](../configs/states/co-calendar-geography.v1.json) is checked against the collection matrix; a changed source or case jurisdiction ID must be resolved before a new worklist is generated.

`stage` is the **furthest repository milestone**, in this order: `published_case`, `source_verified_manifest`, `pending_manifest`, `calendar_configured`, `not_started`. Other columns retain all scheduled calendar and case IDs even when a later stage wins. A source-verified manifest is still blocked from public release until reviewed private captures match its cited bytes. The worklist has no access to private source-review state and cannot imply that a calendar is currently being fetched.

The current extract has 4,104 `not_started` geography entries. That number means no calendar mapping or case manifest is connected in this repository; it says nothing about whether the government has made a relevant decision. New state agencies, tribal governments, public authorities, universities, and intergovernmental bodies require separate sourced roster entries because the current geography file does not enumerate them. The worklist is an operational queue, not a public allegation or a completeness certificate.

At this snapshot, the `not_started` rows are: 1 state, 62 counties, 268 municipalities, 178 school districts, and 3,595 provisional DOLA districts. The other seven rows are one published municipal case, three municipalities with source-verified preview manifests, one county with pending preview manifests, and two calendar-configured jurisdictions (Douglas County and Littleton). A provisional district entry still needs identity and governing-body checks before any case is attached.
