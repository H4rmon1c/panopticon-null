# Colorado geography worklist

Run `python3 web/panopticon-terminal/scripts/build-colorado-worklist.py --output /tmp/colorado-worklist.csv` from the repository. It produces one row for each of the 4,111 archived geography entries. The CSV joins the neutral roster to scheduled HTML calendars, unscheduled document-index profiles, version 2 manifests, and the current static public snapshot through explicit stable IDs. [The calendar mapping](../configs/states/co-calendar-geography.v1.json) is checked against the collection matrix; the [document-index mapping](../configs/states/co-document-index-geography.v1.json) checks three bounded, unscheduled index/PDF policy pairs for [Silver Plume](silver-plume-discovery.md), [Moffat, and Simla](moffat-simla-discovery.md).

`stage` is the **furthest repository milestone**, in this order: `published_case`, `source_verified_manifest`, `pending_manifest`, `calendar_configured`, `document_index_configured`, `not_started`. Other columns retain all scheduled calendar, document-index, and case IDs even when a later stage wins. A source-verified manifest is still blocked from public release until reviewed private captures match its cited bytes. The worklist has no access to private source-review state and cannot imply that a configured source is currently being fetched.

The current extract has 4,101 `not_started` geography entries. That number means no calendar, document-index, or case mapping is connected in this repository; it says nothing about whether the government has made a relevant decision. New state agencies, tribal governments, public authorities, universities, and intergovernmental bodies require separate sourced roster entries because the current geography file does not enumerate them. The worklist is an operational queue, not a public allegation or a completeness certificate.

At this snapshot, the `not_started` rows are: 1 state, 62 counties, 265 municipalities, 178 school districts, and 3,595 provisional DOLA districts. The other ten rows are one published municipal case, three municipalities with source-verified preview manifests, one county with pending preview manifests, two calendar-configured jurisdictions (Douglas County and Littleton), and three towns with unscheduled document-index profiles (Silver Plume, Moffat, Simla). A provisional district entry still needs identity and governing-body checks before any case is attached.
